## 2) 今日已完成功能

### 2.1 空间新建/编辑（含封面）

- 后台空间管理支持新建空间（名称、简介、可见性、分类、封面）。
- 封面支持两种来源：
  - 用户上传：前端裁剪、缩放、导出 `WebP`。
  - 系统生成：前端 `SVG -> Canvas -> WebP`，封面标题取空间名称。
- 封面尺寸约束已统一到 `1600 x 2560`（或等比处理）。
- 后端新增封面资产落库与关联能力，支持再次校验与规范化处理。
- 后续 UI 调整已同步：系统封面改为简约风、去边框，仅保留圆角/背景视觉。

### 2.2 空间管理列表与成员治理

- 空间列表操作栏升级为 `Dropdown Menu` 交互（默认显示“设置”+下拉菜单）。
- 成员管理弹层补齐：添加成员、调整角色、移除成员。
- 修复成员管理弹层重复请求问题与角色选择下拉问题。
- 空间列表支持从标题/封面直接进入对应空间编辑模式。

### 2.3 后端统一返回协议

- 响应结构统一为 `JsonResult`，业务数据统一放在 `Data` 字段。
- `code` 统一为 `int`，并按错误类型分配错误码。
- 状态码策略收敛：后端接口仅返回 `200` 与 `403`，业务失败通过 `code` 表达。
- 已补充并更新相关单测，保证协议与行为一致。

### 2.4 空间分类能力重构

- 分类从“配置表方案”重构为“独立分类表 + 空间关联”。
- 分类支持：新增、重命名、删除（禁止重名）。
- 删除分类时，分类下空间自动迁移到“未分类”。
- 初始化迁移后默认创建“未分类”分类。
- 新建/编辑空间时，分类选择已接入并位于可见性之后。

### 2.5 首页 SSR（Go 模板渲染）

- 首页从 Web SPA 迁移为 Go 模板 SSR，满足搜索引擎抓取需求。
- 新增分类导航与分类页路由：`/explore/:categoryId`。
- 分类展示规则：
  - 固定包含“全部”并置顶；
  - “未分类”固定靠前；
  - 其余按名称升序。
- 空间卡片展示以封面为主，支持 hover 遮罩信息。
- 顶部导航新增登录态展示（登录/注册、头像昵称、下拉菜单）。
- 匿名访问缓存策略已纳入系统配置（默认 `max-age=60, s-maxage=300`），登录用户走实时渲染。

### 2.6 权限收敛与入口治理

## 3) 注意实现与约束（重点）

- **权限优先级**：平台管理员 > 空间管理员 scope；高风险管理操作仍需操作令牌校验。
- **接口契约**：后端统一 `JsonResult`，前端解析 `code + data`，避免混用旧结构。
- **封面一致性**：前端负责生成/裁剪体验，后端必须二次校验并兜底重处理。
- **SSR 缓存分流**：匿名可缓存、登录禁缓存，避免权限可见性数据缓存穿透。
- **路由行为**：
  - 首页/分类页 SSR；
  - 后台空间列表可跳转编辑空间；
  - 编辑器必须带空间上下文访问。
- **分类数据完整性**：分类删除迁移到“未分类”，保证空间不悬挂。
